# Digital-Watch-using-C
A digital watch is created by using only C program. This is my first project in my entire coding life. 

A simple, real-time Digital Watch application built using C language that runs directly in the terminal console.

## 📌 Features
- Continuous real-time time tracking (Hours, Minutes, Seconds).
- Formatted digital time display (`HH : MM : SS`).
- Dynamic screen updating using console clearing.

## 🚀 How to Run
1. Clone or download the repository.
2. Open the file `DigitalWatch.c` in any C compiler (e.g., Code::Blocks, Dev-C++, or GCC).
3. Compile and run the code.

## 🛠️ Built With
- **Language:** C
